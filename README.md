# Motivation
I chose this project because YOLO is something that I enjoyed working with in my undergraduate classes (Senior Design I & II). However, at that time I was only able to work with a very small dataset that was difficult to optimize because of the limited amount of data I could train the YOLO model on. I had the idea for this project when I was searching through YOLO datasets in Kaggle and I came across a dataset with tens of thousands of facial expressions [2]. The idea came about while I was playing a game because whenever I lost I would be sad for a couple of seconds. I wondered if an algorithm could tell when this happens without having any additional information about what I was doing. Some of what I have been doing in Digital Image Processing has been trying to recognize patterns in images and I was wondering if I could get my YOLO algorithm to do the same for facial expressions. I would like my YOLO model to do this as well as a human can because people are able to tell the expressions on another person’s face pretty well. I can tell when the people around me are happy, sad, or angry.
